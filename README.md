➔ About the Project

This mod adds many QOL (Quality of Life) changes to the classic games, this mod includes specific stuff in the zip file: GTA3:R, GTAVC:R, GTASA:R, And soon even custom games!
Some of the most notable improvisations will be better textures, higher quality fonts, widescreen fix, etc.
